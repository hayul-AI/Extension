# ImageConverter - Free Online Image Tools

Professional, private, and instant image tools that run directly in your browser. All processing happens on your device, ensuring your files never leave your computer.

## Features

- **Remove EXIF**: Securely strip sensitive metadata from your photos.
- **Format Conversion**: Convert between PNG, JPG, HEIC, and WEBP.
- **Image to PDF**: Convert images to professional PDF documents.
- **Blur Face / Mosaic**: Censor sensitive areas instantly with local processing.
- **Favicon Generator**: Create multi-size favicon packs for websites.
- **Resize & Crop**: Adjust image dimensions and aspect ratios perfectly.
- **Color Palette**: Extract dominant color schemes from any image.
- **OCR to Text**: Extract editable text from images using high-power OCR.

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Modern Baseline features)
- **Deployment**: Firebase Hosting

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
